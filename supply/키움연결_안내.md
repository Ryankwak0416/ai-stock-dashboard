# 키움 연결 안내 — 수급 체크 앱 (261031)

지금 앱은 공개 원천(네이버)으로 돌아간다. 키움 키를 넣으면 기관 세부 9주체, 업종별 외국인·기관(전 업종), 프로그램 일별 이력, 순위·연속매수(키움 값), 대차잔고가 자동으로 키움 값으로 바뀐다. 화면 맨 위 «키움 연결» 줄에서 결과가 보인다.

## 1. 키 확인 (키움, 브라우저)
키움 REST 포털 openapi.kiwoom.com에 로그인한 뒤 «API 사용신청 → 계좌 APP Key 관리»에서 App Key와 Secret Key를 확인한다. REST를 아직 신청하지 않았다면 «API 신청/해지»에서 먼저 신청한다. 메뉴 이름은 2차 자료(wikidocs·algolab) 기준이다.

## 2. GitHub에 등록 (브라우저, 2분)
github.com/Ryankwak0416/ai-stock-dashboard → Settings → Secrets and variables → Actions → New repository secret
- `KIWOOM_APPKEY` = App Key
- `KIWOOM_SECRETKEY` = Secret Key

실전 키를 넣는다. 모의 키는 실전 서버에서 오류 8030이 나고, 모의 서버가 수급 데이터를 주는지도 확인되지 않았다.

## 3. 시험
Actions 탭 → `supply-probe` → Run workflow를 실행하고, 로그의 «2) kiwoom REST token» 줄을 본다.
- 토큰 칸이 `<NN자>`로 나오면 성공이다. 경로 A(Actions 직접 호출)로 끝나고, 다음 수집부터 키움 값이 들어간다.
- `8010`, `8040`, `8050`, `8103`이나 IP·단말기 문구가 나오면 키움이 호출 IP를 제한하는 것이다. GitHub 러너는 실행마다 IP가 바뀐다(시험에서 버지니아 → 애리조나). 이 경우 4번으로 간다.

## 4. IP 제한일 때 — PC 경로 (D)
1. 키움 포털에서 사무실 PC의 공인 IP를 등록한다(최대 10개).
2. 그 PC의 명령 프롬프트에서 1회만 실행한다.
   - `setx KIWOOM_APPKEY "앱키"`
   - `setx KIWOOM_SECRETKEY "시크릿키"`
   - `pip install requests`
3. 저장소 clone 폴더의 `supply\pc\kiwoom_pc.bat`를 작업 스케줄러에 «평일 18:45»로 등록한다.
4. PC가 `supply/kiwoom.json`(시장 데이터만, 키 없음)을 push하면, Actions 18:50 수집이 그 파일을 합친다.
