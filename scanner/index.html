종합 스코어는 stoch/indicators106.py가 매일 장마감 후 계산합니다. 106개 지표를 각각 과거 250일 백분위(0~100)로 정규화해 스케일을 통일하고, 서로 상관이 높은 지표는 중복군으로 묶어 1/그룹크기 가중치를 줍니다(SMA5~SMA200처럼 같은 정보를 여러 번 세지 않기 위함). 카테고리 가중치는 추세 .20 / 모멘텀 .20 / 이동평균 .18 / 거래량 .15 / 변동성 .12 / 지지저항 .07 / 통계 .04 / 캔들패턴 .04 로 공개·고정돼 있습니다. 스토캐스틱은 저장소가 계산한 %D 값(D5=5·3 / D10=10·6 / D20=20·12)이며 %K가 없어 골든크로스 판정은 하지 않습니다. 볼린저(20·2σ)·MACD(12·26·9)·RSI(14)는 종가로 이 페이지가 직접 계산합니다. 기계적 타점은 규칙이 발화한 지점일 뿐 수익을 보장하지 않습니다. 백테스트 탭에서 이 스코어의 실제 성적을 벤치와 비교해 보세요.
